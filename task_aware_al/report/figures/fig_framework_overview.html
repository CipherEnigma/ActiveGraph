EdgeQuery: Task-Aware Active Link Acquisition Framework
1 Environment / Network
Contextual SBM:
n = 90 nodes, k = 3 classes
pin = 0.13  |  pout = 0.006
~189 true edges per graph
12-dim node attributes (weak)

Observation:
Only 15% of true edges visible
New graph per random seed
2 Input Representation
Observed Graph Gt = (V, Et)
Adjacency matrix At at query step t
Labelled Set L ⊂ V
Known class labels yL ∈ {1…K}
15% or 40% of nodes
Target Set T ⊂ V\L
15 unlabelled nodes to classify
Labels yT hidden from strategy
Budget B = 200 queries
Candidates C = all unobserved pairs
3 Query Strategy (Value Scorer)
For each candidate pair (i,j):
Step 1 — Estimate link probability
P̂(ij) = p̂in Psame + p̂out(1−Psame)
where Psame = Σc qi(c) qj(c)
Step 2 — Compute confidence gain
Add edge tentatively → rerun LP
ΔÂT = ÂT(A+eij) − ÂT(A)
Step 3 — Value score
score(i,j) = P̂(ij) × ΔÂT
↳ Candidate list: top-100 by P̂ × |confi−confj|
↳ Static: score once, ask top-B
↳ Adaptive: re-score after each answer
4 Oracle & Graph Update
Answer = 1 (edge exists):
At+1 = At + eij
True link added to observed graph
Answer = 0 (no edge):
Pair removed from candidates
Graph unchanged
Repeat for t = 1, 2, …, B
5 Classifier: Label Propagation
Closed-Form Solution:
S = D−1A  (row-norm. adj.)

FU = (I−αSUU)−1 αSULYL

Damping α = 0.99
Labelled rows: FL = YL
Prediction: ŷu = argmaxc Fuc
Confidence: maxc qu(c)
Unreached node → prior guess
Why Label Propagation?
  • Exact closed form → no retraining needed
  • Effect of any candidate edge computable in O(n²)
  • Enables scoring all candidates per query
  • Interpretable belief vectors over classes
Estimated confidence on targets:
ÂT(A) = (1/|T|) Σu∈T maxc qu(c)
